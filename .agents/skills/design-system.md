# Design System Specification

## Color Palette Map
- Background Gradient: Deep Twilight (`#14011a`) -> Cosmic Plum (`#2d0a3d`) -> Fuchsia (`#9b0050`) -> Sunset Orange (`#e63900`) -> Warm Sand (`#fae3d2`)
- Accents:
  - `disco-neonPink`: `#ff007f` (Primary CTA & highlights)
  - `disco-neonGreen`: `#39ff14` (Scientific callouts, active state, checkmarks)
  - `disco-peacockTeal`: `#00f5d4` (Water element & sub-navigation)
  - `disco-radiantGold`: `#ffd700` (VIP tier, sacred geometry, badges)

## Component Styling Rules
- Cards: Must use `luxury-glass rounded-3xl p-6 sm:p-8 border border-white/10`.
- Text Shadows: Use `.neon-shadow-text` or `.gold-shadow-text` on large headings over vibrant background sections to preserve contrast and legibility.
